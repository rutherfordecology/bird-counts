Keeping your data safe

Each tap is saved on the phone as you go, and a count you haven't finished comes back if the phone dies or the app closes. Saved counts stay until you delete them. To protect against losing the phone, turn on the GitHub backup below, and/or use Data → Back up now.

Backup to GitHub

When there's reception, saved counts are copied to a GitHub repo automatically: one CSV and one JSON per day, plus a full backup. Every change is kept in the repo's history.
